# Architecture

Folder `architecture` berisi desain arsitektur sistem PROJECT365. Dokumen di dalam folder ini menjelaskan struktur sistem, desain data, integrasi, deployment, dan aspek keamanan yang diperlukan untuk membangun solusi berdasarkan kebutuhan bisnis.

Architecture menjelaskan bagaimana sistem dibangun berdasarkan kebutuhan bisnis.

## Subfolder

- `system`: desain struktur dan komponen utama sistem.
- `database`: desain penyimpanan data, model data, dan relasi data.
- `integrations`: desain integrasi dengan sistem, layanan, atau provider eksternal.
- `deployment`: desain strategi deployment dan lingkungan operasional.
- `security`: desain keamanan sistem, akses, dan perlindungan data.
