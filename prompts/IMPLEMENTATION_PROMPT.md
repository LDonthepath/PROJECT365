# Implementation Prompt

Read:

- docs/
- specs/
- issues/

Implement ONLY the assigned issue.

Requirements:

1. Follow Technical Design exactly.
2. Do not add features.
3. Do not modify architecture.
4. Do not refactor unrelated code.
5. Keep implementation small and simple.
6. Create unit tests.
7. Explain implementation decisions.

Before coding:

- identify dependencies;
- identify acceptance criteria;
- identify edge cases.

After implementation provide:

- files created;
- files modified;
- tests created;
- assumptions made;
- potential risks.

Stop after the issue is completed.
