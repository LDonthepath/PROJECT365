# Implementation

Folder `implementation` berisi artefak implementasi PROJECT365 yang digunakan selama proses development.

Folder ini berisi prompt AI, hasil review, dan dokumen migrasi yang digunakan selama proses development.

## Subfolder

- `prompts`: prompt AI yang digunakan untuk mendukung proses implementasi.
- `reviews`: hasil review teknis, dokumentasi pemeriksaan, dan catatan evaluasi implementasi.
- `migrations`: dokumen migrasi yang menjelaskan perubahan terstruktur selama development.
